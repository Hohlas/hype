# Алгоритм бота: спот-сетка с отложенными ордерами

Параметры (значения задаются в конфигурации):

- `TOKEN` — торгуемый спот-актив.
- `STEP` — шаг сетки в долларах: дистанция между уровнями входов и цель каждого тейка.
- `SIZE_PCT` — размер одного входа в процентах от доступного USDC.
- `AGGR` — доля шага для входа вдогонку растущей цене.
- `COOLDOWN` — пауза перед повторным входом на тот же уровень.

## 1. Цикл

Бесконечный цикл с паузой между итерациями. Каждая итерация получает: текущую спот-цену, открытые ордера, балансы. Открытые ордера делятся на лимитные покупки (BuyLimit, всегда не более одного активного) и лимитные продажи (тейки). По висящим тейкам определяются `min_TP` (самая низкая цена продажи) и `max_TP` (самая высокая).

Размер каждого входа — `SIZE_PCT` от доступного USDC, но не ниже биржевых минимумов. По мере траты USDC следующие входы уменьшаются; глубина сетки ограничена только доступным USDC.

## 2. Три ветки входов

1. **Первый вход** — если висящих тейков нет вообще: покупка по рынку на размер входа по текущей цене.
2. **Усреднение вниз** — лимитный ордер на покупку по цене `min_TP − 2×STEP`. Ставится только при отсутствии активного BuyLimit и висит до исполнения. Устаревший ордер отменяется: если его цена оказалась ниже `min_TP − 2.5×STEP`, он снимается и выставляется заново по актуальной формуле.
3. **Вход вдогонку вверх** — покупка по рынку, если текущая цена выше `max_TP − AGGR×STEP`.

## 3. Правило повторного входа

Один исполненный вход — один тейк. Повторная покупка на том же ценовом уровне запрещена, пока не подтверждено исполнение тейка предыдущего входа с этого уровня. Нарушение запрета дополнительно сдерживается паузой `COOLDOWN` после исполнения тейка.

При старте бот находит покупки без тейков и ставит на них тейки; если для тейка не хватает свободного остатка (меньше биржевого минимума), постановка откладывается до появления баланса.

## 4. Тейки и учёт прибыли

На каждую новую покупку ставится лимитный ордер на продажу всего купленного объёма по цене `вход + STEP`. Исполнение тейка подтверждается историей сделок. Прибыль сделки = фактическая выручка продажи минус фактические затраты покупки (цены и комиссии исполнения, при частичном исполнении — пропорционально проданной доле). Если покупка в истории не найдена, прибыль оценивается как `STEP` минус комиссии обеих сторон.

Каждая операция записывается в таблицу статистики и отправляется в Telegram.

## 5. Границы

Стоп-лоссов нет, тейки не отменяются и не двигаются: купленный актив удерживается в споте неограниченно долго. В монотонном росте каждый вход продаётся целиком на `вход + STEP`, поэтому позиция в тренде мала и сетка отстёт от buy-and-hold.
