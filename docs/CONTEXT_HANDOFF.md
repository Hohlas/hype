# Живое состояние проекта (передача контекста)

Обновлено: 2026-10-14. Это текущее рабочее состояние, не устройство алгоритма
(оно в `docs/project_description.md`) и не архитектура дежурства (она в
`docs/GithubActions.md`). Не дублировать сюда эти два документа.

## Что сделано в этой сессии

Перенос на дежурство в GitHub Actions по лестнице §10 `GithubActions.md`.
Реализован **не торгующий слой** (шаги 1–2: разбор), плюс маяк.

- `modules/ci_loader.py` (новый) — чтение `WALLETS_DATA` и TG-токенов из
  окружения; битый/пустой `WALLETS_DATA` в CI = быстрый отказ.
- `main.py` — `get_runtime_mode()` (явная `BOT_RUNTIME` → авто по `WALLETS_DATA`),
  `run_ci()` с режимом из `BOT_MODE` (0/4/5) без единого `input()`;
  `run_vps_interactive()` — прежнее меню.
- `modules/database.py` — `DB_ENCRYPTION_PASSWORD` первым, интерактив только
  в VPS-режиме; в CI интерактив невозможен → `DataBaseError`.
- `modules/wallet_loader.py`, `modules/utils/utils.py` — сначала окружение,
  потом файлы.
- `modules/utils/modes.py` — `inquirer` импортируется лениво; `get_mode_from_env()`.
- `modules/delayed_orders_strategy.py` — выход по `WATCH_SECONDS` вверху
  итерации, пауза из `BOT_POLL_INTERVAL` (дефолт локально 10 с, в дежурстве 60).
- `modules/duty.py` — сшивка разбора, маркер работы в ветку, диагностика
  зазоров, стук сердца ожидающего, PUT через Contents API.
- `modules/duty_parse.py`, `modules/beacon.py` (новые) — итерация разбора
  (только чтение) и маяк в канал (§1.5).
- `.github/workflows/bot.yml` — эстафета по крону `7,19,33,46,58`, лимит 355,
  бюджет `330+15+1`, `if: always()` и маски секретов.
- `tests/` (21 тест) — слияние, наследование дедлайна, бюджет, CI-загрузка.

## Открытые вопросы / риски

- Сеть до `api.github.com` из рабочего окружения периодически рвётся
  (TLS handshake timeout) — на код и раннеры не влияет, мешает только `gh`.
- Дежурство 24/7 на бесплатном тарифе возможно только при public-репо
  (при private лимит 2000 мин/мес не покрывает). Сейчас public — условие
  выполнено.
- `parse_mode` в логе шумит ошибками по USDC/USDT (нет цен для этих тикеров) —
  существующее поведение, к переносу не относится.
